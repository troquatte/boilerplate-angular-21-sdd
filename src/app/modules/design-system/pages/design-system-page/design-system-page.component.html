Tables

Não há estilos customizados de tabela no design system. O projeto utiliza a estrutura de grid do Bootstrap para layouts tabulares. Abaixo um exemplo com a classe .ds-table (estrutural, não um token de produto).

Nome E-mail Perfil
João Silva joao@email.com Admin
Maria Souza maria@email.com Cliente

Exemplo de código

<table class="ds-table">
  <thead>
    <tr>
      <th>Nome</th>
      <th>E-mail</th>
      <th>Perfil</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>João Silva</td>
      <td>joao@email.com</td>
      <td>Admin</td>
    </tr>
  </tbody>
</table>
